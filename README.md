# Dati sulle visite annuali dei musei italiani più visitati dal 2000 al 2024
Questo progetto analizza e visualizza i dati dei musei più visitati in Italia dal 2000 al 2024, mostrando trend di visitatori, confronti tra istituzioni e variazioni nel tempo tramite grafici.
Scarica [qui](https://github.com/AlessiaTettamanti/LaboratorioInformatica/blob/cba49ba4e40e807e272b863791727b27c9830d53/MuseiItaliani.xlsx) il dataset e l'elaborazione dei dati per tre diversi case studies.
Visita la [pagina](https://alessiatettamanti.github.io/LaboratorioInformatica/) del progetto per avere informazioni in più.
